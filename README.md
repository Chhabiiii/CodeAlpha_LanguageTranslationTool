# 🌐 LinguaTranslate

LinguaTranslate is a simple language translation web application built using Python and Streamlit. It allows users to enter text, select a source language and target language, and translate the text using an online translation API.

## ✨ Features

- Translate text between multiple languages
- Select source and target languages
- Simple and user-friendly interface
- Display translated text
- Copy translated text with one click
- Error handling for connection problems
- Responsive Streamlit-based interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Requests
- MyMemory Translation API

## 🌍 Supported Languages

- English
- Hindi
- French
- Spanish
- German
- Italian
- Portuguese
- Russian
- Japanese
- Korean
